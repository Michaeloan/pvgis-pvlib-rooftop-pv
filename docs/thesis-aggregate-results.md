# 广州屋顶光伏技术潜力研究案例

本页仅展示作者提供的论文当前稿（2026-09-23）的少量城市级汇总结果。论文全文、作者个人信息、原始建筑数据、逐栋空间结果和调查材料不随仓库发布。

## 主要评价边界

主要评价边界排除城中村住宅子组。该边界内的技术估计为：

| 指标 | 汇总结果 | 含义 |
|---|---:|---|
| 屋顶适装面积 | 177.94 km² | 按研究的屋顶利用率与布置规则，从屋顶足迹折算得到 |
| 直流技术装机容量 | 37.37 GWp | 适装面积与组件容量密度对应的技术容量 |
| 典型气象年技术发电潜力 | 43.35 TWh/a | 在研究设定的气象与遮挡模型下估计的年交流电量 |
| 运行期年减排量 | 19.15 Mt CO₂/a | 用2023年广东省电力平均排放因子折算的运行期估计 |

同一技术模型下，城中村住宅子组另有约 **10.73 TWh/a** 条件性发电储备。它不并入43.35 TWh/a主要评价结果，也不表示已经具备实施条件。

这些结果是论文模型在特定建筑底图、样本标定、气象输入和评价边界下的研究发现；它们不是本仓库合成建筑示例的输出。公开代码提供可调计算入口和复算记录格式，但要复算论文总量仍需未公开的原始数据与完整研究流程。因此，仓库不把这些总量写成默认参数、测试通过条件或演示数据的“标准答案”。
